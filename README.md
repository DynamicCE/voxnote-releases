# Voxnote — releases

Voxnote is a small Windows app that turns speech into note cards: press a
hotkey anywhere, talk, press again. A second hotkey pastes the dictated text
into whatever app has the focus.

This repository only hosts the installers. Download the latest `.exe` from the
[Releases](https://github.com/DynamicCE/voxnote-releases/releases/latest) page.
The installer upgrades an existing installation in place, and the app checks
here for updates on start (nothing is downloaded until you click "Download").

The builds are not code-signed, so Windows SmartScreen may show "Windows
protected your PC" once: click *More info → Run anyway*.
