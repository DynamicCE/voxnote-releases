# Voxnote

Voxnote is a small Windows app that turns speech into note cards: press a
hotkey anywhere, talk, press again. A second hotkey pastes the dictated text
into whatever app has the focus.

Voxnote is distributed through the **Microsoft Store** (free 7-day trial, then
a monthly subscription inside the app). The Store installs and updates it;
there are no downloads here.
